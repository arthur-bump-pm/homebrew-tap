# Homebrew tap

Casks by [arthur-bump-pm](https://github.com/arthur-bump-pm).

## Awake

[Awake](https://github.com/arthur-bump-pm/awake-mac) keeps your Mac running and online while you work away from your desk.

```bash
brew install --cask arthur-bump-pm/tap/awake
```

Update with `brew upgrade --cask awake`, remove with `brew uninstall --cask awake` (add `--zap` to remove its settings too). The cask also puts `awakectl` on your PATH.
